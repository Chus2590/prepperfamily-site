🐿️ Despensa de Palabras

Ayuda a Nuez, la ardilla, a llenar su despensa antes del invierno. Forma palabras y guarda provisiones.

Puntos: 0 / 300 Total: 0 Racha: 0 Récord: 0
🌱 El Huerto
Empieza la cosecha: junta palabras y guarda tus primeras provisiones.

🎉 ¡Despensa llena!

Cómo se juega

  • Toca letras vecinas (también en diagonal) para formar una palabra de 3 letras o más.
  • Pulsa Guardar palabra para guardarla: las letras se van y caen unas nuevas.
  • Las letras doradas son bellotas: valen el doble. Las palabras de 6 letras o más dan +50.
  • Cada palabra seguida suma un extra por racha. Completa la meta de cada mundo para avanzar.

Juego original de PrepperFamily.org. Formar palabras con letras es una mecánica genérica: el nombre, el personaje y el arte son propios.
